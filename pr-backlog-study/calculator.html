Method. Backlog counts are live from GitHub search. Diff-size statistics come from 119 open PR heads fetched and diffed locally against their own merge-base. Token figures per stage are anchored on one completed pilot leg — a stale physics-server change, 3,696 commits behind master, 14 files conflicting — carried through rebase, review, defect fixes, new tests, and a revert-proof that the tests catch the bug they claim to. Build times are wall-clock on 4 cores with ccache. Costs are list API prices; batch discounts and self-hosting are not modelled. The model deliberately excludes anything the pilot did not measure.
